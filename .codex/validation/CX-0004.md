# Validation Record: CX-0004

**Task:** `CX-0004 — Align Opportunity.stage Domain and Database Schema`
**Status:** `COMPLETED`
**Date:** 2026-08-01

## Scope and Decision

The TypeScript `Opportunity.stage` union and both SQL `chk_opportunity_stage` constraints already agreed on these values:

```text
discovery, need_confirmed, proposal_drafting, proposal_review, won, lost
```

The failure came from `scripts/validate-domain-schema-alignment.mjs`, which scanned the first `stage:` field anywhere in `src/types/domain.ts`. Earlier media stage fields caused it to return an empty set before it reached `Opportunity.stage`.

CX-0004 now uses the installed TypeScript Compiler API to locate exactly one `Opportunity` type/interface and exactly one direct `stage` property. It accepts only direct string-literal values, rejects missing or duplicate declarations/properties, and reports TypeScript/database differences in both directions.
