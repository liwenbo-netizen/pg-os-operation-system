### 修复的生成器缺陷（均为渲染错误，非 Baseline 语义变更）

1. 生成列（`GENERATED ALWAYS AS ... STORED`）曾被渲染为 DEFAULT —— 采集 `attgenerated` 后修正；
2. 约束/索引顺序：唯一索引必须先于引用它的外键创建；
3. SQL 扫描器不识别带标签美元引号（`$function$`/`$fn$`），函数体被错误切分；
4. Management API 网关 503/连接超时为瞬时传输故障，加入幂等重试（仅网络/5xx，SQL 400 不重试）；
5. Diff 归一化：`(ARRAY['v'::type,...])::text[]` 与 `ARRAY[('v'::type)::text,...]` 是 PostgreSQL
   重解析产生的等价形式，已在 Sandbox 上用只读 SELECT 证明等价（array_expression_equal=true、
   membership_equal=true、view_predicate_equal=true），并加入窄范围规范化；未把任何真实业务差异归为非语义。
